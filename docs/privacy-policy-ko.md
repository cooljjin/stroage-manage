# Stockly 개인정보 처리 안내

최종 갱신 예정일: 보안 강화 릴리스 적용일

이 문서는 보안 강화 소스에 맞춘 정책 초안입니다. 실제 서비스에 게시하기 전 사업자 정보, 문의처, 시행일과 적용된 서버 설정을 확인해야 합니다.

## 처리하는 정보와 목적

- 계정 및 인증: 이메일, 인증 제공자 식별자, 표시 이름을 로그인과 계정 관리에 사용합니다.
- 매장 업무: 재고, 상품, 발주, 할 일, 인수인계, 레시피 자료를 매장 운영 기능 제공에 사용합니다.
- 레시피 자동 가져오기: 사용자가 명시적으로 올린 Excel, CSV 또는 PDF 원본과 추출에 필요한 문서 내용을 Google Gemini로 전송해 메뉴와 재료 구조를 분석합니다. 분석 결과는 저장 전 사용자가 검토합니다.
- 보안 및 감사: 작업 실행자, 실행 시각, 요청 식별자, 변경 전후 수량과 제한 승인 기록을 중복 처리 방지와 사고 조사에 사용합니다.

## 보관 및 삭제

- 레시피 원본 파일은 작업 생성 시점부터 최대 7일 보관한 뒤 자동 삭제 대상으로 처리합니다. 정규화된 검토 결과와 비용·감사 정보는 원본과 분리합니다.
- 구성원이 없는 개인 매장 관리자가 탈퇴를 요청하면 30일 동안 복구할 수 있습니다. 기간 안에 복구하지 않으면 계정과 개인 매장 데이터가 영구 삭제 대상이 됩니다.
- 자동 삭제 작업은 대상 수, 성공·실패 수와 식별 불가능한 오류 코드만 90일 보관합니다. 파일명, 토큰, 비밀값은 삭제 작업 기록에 저장하지 않습니다.
- 자동 삭제가 실패하면 해당 대상은 삭제 완료로 표시하지 않고 다음 실행에서 다시 검증합니다. 다른 대상의 삭제는 계속 진행하며, 반복 실패는 운영자가 오류 코드와 서버 상태를 확인해 조치합니다.

## 외부 처리자와 국외 전송 가능성

레시피 자동 분석을 선택한 경우 문서 내용이 Google의 Gemini API 처리 환경으로 전송될 수 있습니다. 전송 목적은 레시피 표 구조 추출이며, 계정 비밀번호나 인증 토큰은 전송하지 않습니다. 실제 서비스 게시본에는 계약 주체, 이전 국가, 이전 시점·방법, 보유 기간과 거부 방법을 현재 계약 및 Google 정책에 맞춰 추가해야 합니다.

## 이용자의 선택과 보호 조치

- 레시피 자동 가져오기를 사용하지 않고 레시피를 직접 입력할 수 있습니다.
- 매장 관리자는 같은 매장의 직원 정보를 업무에 필요한 범위에서 조회하며, 일반 직원 디렉터리는 표시 이름과 역할만 제공합니다.
- 인증 토큰과 서버 비밀값은 클라이언트 코드나 감사 로그에 저장하지 않습니다.
- 계정 탈퇴, 30일 안의 복구와 개인정보 문의는 앱의 계정 관리 또는 게시 예정인 문의처를 통해 요청할 수 있습니다.
