# 검증 이력 보관소

이 디렉터리는 과거 테스트·원격 읽기 전용 확인의 증적을 보관한다.

## 사용 범위

- 일반 구현, 버그 수정, 빌드·lint 작업 전에는 이 디렉터리를 읽을 필요가 없다.
- 현재 작업 기준과 미완료 항목은 `docs/stockly-todo-list.md`, `README.md`, `AGENTS.md`를 우선한다.
- 과거 검증 결과를 감사하거나 동일 문제를 재현할 때만 해당 날짜의 이력 문서를 확인한다.
- 이력은 당시 환경을 기록한 것이므로 현재 DB, 계정, 매장, 배포 상태를 보증하지 않는다.

## 보관 원칙

- 테스트 계정, 매장 식별자, 토큰 등 환경별 식별 정보는 기록하지 않는다.
- 새 검증 이력은 날짜와 범위, 수행한 확인, 결과, 남은 검증만 간결하게 작성한다.
- 현재 기준 문서를 과거 결과로 되돌리거나 덮어쓰지 않는다.
