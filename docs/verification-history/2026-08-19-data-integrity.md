# 2026-08-19 데이터 정합성 원격 검증 이력

> 보관 출처: `agent/record-data-verification`의 `f8e244b` 커밋
>
> 이 문서는 당시 원격 읽기 전용 검증 기록이다. 현재 테스트 환경이나 배포 상태의 기준 문서가 아니다.

## 범위

- `DATA-007`: 재고, 재고 로그, 발주 확정 상태 진단
- `DATA-008`: 중복 저장 방지용 idempotent 재고 작업

## 확인 결과

### DATA-007 — 매장 데이터 정합성 진단

- 진단 RPC가 원격 DB에 존재하는 것을 확인했다.
- 익명 호출은 거부됐고, 인증된 호출만 허용됐다.
- 당시 테스트 관리자 역할로 연결된 테스트 매장을 진단한 결과 불일치는 없었다.
- 직원 역할 호출은 매장 관리자 권한 오류로 거부됐다.
- 운영 콘솔은 `master` 역할을 요구하므로, 관리자 콘솔 화면 검증에는 별도의 master 세션이 필요하다고 기록했다.

### DATA-008 — 중복 저장 방지

- 동일한 `request_id`로 `record_inventory_operation_idempotent_v2`를 두 번 호출했을 때 같은 로그 ID와 수량이 반환됐다.
- `(store_id, user_id, request_id, operation_type)` 고유 제약으로 요청 행은 한 건만 생성됐다.
- 전체 트랜잭션을 rollback한 뒤 수량, 로그, 요청 행이 원상복구되는 것을 확인했다.

## 당시 남은 검증

- 관리자 콘솔의 브라우저 화면 검증
- 실제 브라우저에서 네트워크 차단 뒤 같은 요청 ID로 재시도하는 흐름 검증

## 현재 작업 시 유의사항

- 당시 사용한 테스트 매장·계정·식별자는 현재 표준 테스트 환경과 다를 수 있으므로 재사용하지 않는다.
- 현재 검증 대상, 접근 권한, migration 및 배포 상태는 `docs/stockly-todo-list.md`와 현재 시스템 상태를 기준으로 다시 확인한다.
